## Firebase setup

The app uses Firebase Authentication for accounts and SQLite as its offline
cache. Configure the Firebase project once on a development machine:

```text
dart pub global activate flutterfire_cli
flutterfire configure
```

Enable Email/Password in Firebase Console > Authentication > Sign-in method.
For Android, make sure `google-services.json` is generated by the FlutterFire
setup. Do not commit Firebase service-account credentials.

The Vercel backend also needs this environment variable:

```text
FIREBASE_SERVICE_ACCOUNT_JSON=<the Firebase Admin SDK service-account JSON>
```

The MongoDB documents now use `ownerId` from the verified Firebase token. The
existing anonymous SQLite rows do not have an owner and will not appear after
an account signs in; migrate them to an account deliberately before deleting
or reusing the old database.

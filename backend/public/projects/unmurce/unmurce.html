01 / ARCHITECTURE & CORE CAPABILITIES

Engineered for Privacy & Instant Action

No third-party trackers, no invasive analytics. Just clean personal financial management.

AI INFERENCE

Multi-Model Receipt OCR

Take a photo of any printed purchase receipt. The serverless backend leverages Azure Document Intelligence and Gemini 3.6 Flash / Groq LLMs to extract itemized lists, normalize IDR amounts, and split tax & service charges proportionally across items.

Gemini 3.6 Flash Groq Vision Azure OCR NDJSON Stream
SECURITY & AUTH

Per-User Data Isolation

All database queries and sync operations are strictly authenticated with Firebase Bearer ID Tokens. MongoDB Atlas collections enforce per-user indexing (`ownerId`) to guarantee that financial data remains strictly private and sandboxed.

Firebase Token Auth MongoDB Atlas Bearer Verification Encrypted Transport
MOBILE & ENGINE

Native Android & Notification Hooks

Shipped as an optimized Flutter release APK with native Kotlin bridges. Supports bank SMS and local transaction notification parsing to automatically log expenses without manual keyboard entry.

Flutter Kotlin Local Notification Offline SQLite
REPORTING & EXPORT

Audit & PDF Report Generation

Filter expenses by date range, category, or transaction type (Expected vs. Unexpected). Generate downloadable client-side PDF statements instantly via jsPDF without sending data to external render engines.

Client-Side PDF Category Breakdown IDR Formatting Realtime Calculations

06 / FREQUENTLY ASKED QUESTIONS

                    
Developer & User Insights

                

                
Clear answers regarding security, offline syncing, and Android deployment.

            


            

                

                    
                    

                        Uploaded receipt images are processed entirely in memory via secure serverless functions. Images are converted into temporary memory buffers, passed to the vision inference API through encrypted TLS channels, and never stored on public buckets or sold to third-party data aggregators.
                    

                


                

                    
                    

                        Yes! The Flutter client features a local SQLite persistent store. You can record transactions, categorize expenses, and review monthly totals without any network connection. As soon as you re-connect, changes sync seamlessly to MongoDB Atlas.
                    

                


                

                    
                    

                        By default, receipts are routed to Groq's high-speed Vision model for sub-second inference. If the upstream provider experiences rate-limiting or latency spikes exceeding 3000ms, the system automatically redirects the payload to Google Gemini 3.6 Flash without interrupting the user.

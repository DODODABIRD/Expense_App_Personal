SYSTEM OVERVIEW

Unmurce Technical Specification & Tech Stack

Unmurce is a multi-platform personal finance management system created by Orlando Diamond Prasetyo. It features real-time expense tracking, automated receipt split-parsing via Google AI (Gemini 3.6 Flash) and Azure Document Intelligence, combined with secure cross-device authentication.

MONGODB SCHEMAS

03. Mongoose Expense Schema

Each transaction record is isolated per user using the Firebase ownerId claim:

const ExpenseSchema = new mongoose.Schema(
  {
    ownerId: { type: String, required: true, index: true },
    localId: { type: String, required: true },
    name: { type: String, required: true },
    amount: { type: Number, required: true },
    category: { type: String, required: true },
    type: { type: String, required: true }, // 'expected' | 'unexpected' | 'others'
    date: { type: String, required: true },
  },
  { timestamps: true }
);

ExpenseSchema.index({ ownerId: 1, localId: 1 }, { unique: true });
SECURITY

04. Firebase Authentication Middleware

All incoming REST API requests are authenticated using Firebase Admin SDK idToken verification:

async function requireAuth(req, res, next) {
  try {
    const header = req.headers.authorization || "";
    if (!header.startsWith("Bearer ")) {
      return res.status(401).json({ error: "Authentication required" });
    }
    req.user = await admin.auth().verifyIdToken(header.substring(7));
    next();
  } catch (err) {
    res.status(401).json({ error: "Invalid or expired token" });
  }
}
AI INTEGRATION

05. Receipt OCR Parsing (Google AI & Azure Fallback)

When a photo of a receipt is uploaded to /api/parse-receipt, the backend executes an automated AI vision extraction pipeline:

  1. Primary Model (Google AI API / Gemini 3.6 Flash): Multimodal vision model extracts line items, purchase date, item quantities, and tax distributions in structured JSON format.
  2. Fallback Model (Azure Document Intelligence): If Gemini encounters rate limits (HTTP 429) or service degradation, the request automatically falls back to Azure Document Intelligence prebuilt receipt model.
  3. Tax & Service Charge Proportional Split: Tax (PPN) and service charges are calculated and distributed proportionally across all line items to ensure accurate per-item expenses.

07. Setup & Build Guide

Backend (ExpressJS, MongoDB, Vercel)

# 1. Install dependencies
npm install

# 2. Configure environment in .env
MONGODB_URI=mongodb+srv://user:pass@cluster.mongodb.net/unmurce
FIREBASE_SERVICE_ACCOUNT_JSON={"type":"service_account",...}
GEMINI_KEY=AIzaSy...
AZURE_DOCUMENT_INTELLIGENCE_ENDPOINT=https://your-instance.cognitiveservices.azure.com/
AZURE_DOCUMENT_INTELLIGENCE_KEY=your-key

# 3. Run development server
npm start

Mobile Application (Flutter, Kotlin, Gradle)

# 1. Get Flutter dependencies
flutter pub get

# 2. Build Android APK using Gradle
flutter build apk --split-per-abi --release

Web Frontend (NextJs / HTML5)

# Serve static web frontend with live reload
npm run dev
